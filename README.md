# PIS LAB

## 更新网页内容

学生无需编辑 HTML。拉取最新版仓库后运行：

```bash
npm install
npm run content:studio
```

然后打开 `http://127.0.0.1:4174/`，通过表单添加 Working System 或实验室成员。

完整字段说明、审核和发布流程见 [CONTENT_GUIDE.md](CONTENT_GUIDE.md)。

如果学生只需要提交材料、不在本地运行工具，可直接复制并填写 [PIS_LAB_CONTENT_SUBMISSION_TEMPLATE.md](PIS_LAB_CONTENT_SUBMISSION_TEMPLATE.md)，再将填写后的 Markdown 文件和原始图片交给负责人。
